# Gunner 2.0

Arcade helicopter shooter. Survive endless waves of helicopters, chain kills for score multipliers, grab parachuted power-ups and take down the Iron Stallion boss every fifth wave.

## Controls

| Action | Keyboard / mouse        | Gamepad            |
| ------ | ----------------------- | ------------------ |
| Move   | A / D or arrow keys     | Left stick / D-pad |
| Jump   | W / Space (double jump) | A (double jump)    |
| Aim    | Mouse                   | Right stick        |
| Shoot  | Left click              | RT / RB            |
| Dash   | Shift or right click    | LT / LB / B        |
| Pause  | P / Esc                 | Start              |

## Gameplay

- **Enemies**: scouts (fast, small), gunships (spread shots), bombers (drop mines) and a boss every 5 waves.
- **Combo**: kills within 3 seconds of each other raise the score multiplier, up to x8. Taking damage resets it.
- **Power-ups**: health, rapid fire, ricochet, spread shot and laser.
- **Lives**: 3 lives, extra life every 30,000 points. Clear a wave without damage for a perfect bonus.

## Setup

### CMake

```bash
cmake --preset debug
cmake --build --preset debug
```

The game is built to `build/debug/target/`.

### Build Emscripten

```bash
emcmake cmake --preset debug
cmake --build --preset debug
```

## Assets

- Sound effects and music are generated by `tools/gen_sounds.py` (standard library only): `python3 tools/gen_sounds.py`
- Font: [Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P), SIL Open Font License (`assets/fonts/OFL.txt`).
- `art/` holds source and reference art that is not shipped with the game.
